    Sample Lens — implementation plan

    Replaces the "Sample Lens (Demo)" tab with the real feature: one sample, every population, checked against an unsupervised clustering of the same events. Our answer to CytoFLEX's single-sample analysis page.

    Status record: the phase checklist below. Resume at the first unchecked phase. One branch (feature/sample-lens-demo), one commit per phase.

    What the user gets

    1. Gating path with backgating. Pick a population: every gate on its path is shown as a live plot of its parent population, with the picked population's events highlighted. Gates on these plots are the real gates — dragging one edits it and propagates it like anywhere else.
    2. Gate audit. Using a UMAP + HDBSCAN run of the sample, each cluster is compared with the final populations. Findings, in plain language: missed population (a cluster no final gate holds), gate merges clusters, gate cuts a cluster.
    3. Across samples. For the picked population: its % parent in every sample that has it, flagged when the gate edge sits in a dense part of that sample's data, or when its % parent is an outlier.
    4. Fix a missed population. Propose ordinary rectangle gates on real channels that recover the cluster; add them to the tree through the gate coordinator (so undo, propagation and stats all work).

    Design notes

    • Scope of an audit = the UMAP run. A run covers a subsample (indices) of one population (node_id). Only the leaf populations under that node are judged, and only on the run's events. The UI says so.
    • Final population = leaf of the gate DAG, excluding UMAP-exported cluster nodes (is_umap_parent subtrees) — those come from the clustering itself.
    • Edge density, any gate shape: an event is "on the edge" if nudging it by a small step in display space (±x, ±y) flips its membership. Works for every gate type through Gate.contains, no per-shape geometry.
    • Gate synthesis works in display space (the gate's own channel scales), then converts the box back to raw values for a RectangleGate.
    • Analysis lives in analysis/sample_lens/ and stays Qt-free.
